## Sobre

Projeto de estudos desenvolvido durante a trilha **Discover, da Rocketseat**. A proposta é criar uma página pessoal simples, que concentre redes sociais e links de interesse sem exigir navegação por diferentes plataformas.

## Recursos

- Alternância entre **temas claro e escuro** com JavaScript.
- Links para GitHub, LinkedIn e currículo.
- Ícones de redes sociais e ação de contato por e-mail.
- Layout responsivo, com imagens de fundo específicas para telas menores e maiores.

## Tecnologias

**HTML · CSS · JavaScript** — sem framework e sem necessidade de backend.

## Como executar

1. Clone ou baixe este repositório.
2. Abra `index.html` em um navegador.
3. Utilize o botão de alternância de tema e explore os links.

## Estrutura

~~~text
index.html   conteúdo da página
style.css    aparência, temas e responsividade
script.js    alternância de tema e contato
assets/      avatar, ícones e imagens de fundo
~~~

> **Nota:** os links e dados exibidos na página refletem a versão original do projeto de estudos; alguns destinos podem estar desatualizados.
